# Anti-SaaS checklist

Kill these on sight:

- Purple / indigo mesh (`#7C3AED`, `#6366F1`, `#8B5CF6`)
- Inter, Poppins, Roboto, Nunito
- 16px+ rounded white cards with soft drop shadows
- Centered hero + one pill button labeled Connect Wallet
- “The future of finance” / “seamless” / “next-gen” copy
- Rainbow kit network modal as the primary chain UI
- Friendly mint-green eco badges for gas
- Stock three-column feature grid with line icons
- OpenSea-style NFT tiles as the only hero

Replace with:

- Soot brick + mortar grid
- Chakra Petch lockup, Share Tech Mono HUD
- Cyan live, gold value, magenta heat
- HUD corners (2px ticks)
- Classified kickers (`CLASSIFIED VAULT // BRICK SECTOR`)
- Scanlines you can barely see
